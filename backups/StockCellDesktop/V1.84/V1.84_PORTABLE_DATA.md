# V1.84 Portable Data

- EXE 旁边自动创建 `data/`。
- `UserData`、`SessionData`、`Cache`、`Logs` 全部保存到当前 EXE 目录。
- 第一次运行会从旧的 `%APPDATA%\stock-cell-desktop` 只迁移必要设置：Local Storage、Preferences、窗口位置。
- 不迁移旧 Chromium Cache，避免把 C 盘的大缓存复制过去。
- 磁盘缓存限制约 50 MiB，媒体缓存约 10 MiB。
- 迁移成功并确认自选股/设置正常后，可以手动删除旧的 `%APPDATA%\stock-cell-desktop` 文件夹。
